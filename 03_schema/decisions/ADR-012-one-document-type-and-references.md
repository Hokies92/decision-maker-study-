# ADR-012 — One document type; every reference enforced

**Status:** proposed (P3.S01) · **Provenance:** INFERRED (Claude)

## Context
The plan needs a full study, a one-thread slice, and a respondent file (P3.S03), and every reference must be checkable.

## Decision
- One root element, `Study`, for every instance. Its sections (`Instrument`, `Population`, `Grouping`, `Results`, `Variables`, `Graph`, `Respondents`) are each optional, in fixed order.
- Every instance is self-contained: anything referenced must be present in the same document. A slice includes the items, scales, cohorts, dimensions, groups and gates its results and links use.
- References are enforced with `xs:key` / `xs:keyref` (XSD 1.0, checked by `xmllint`). IDs are project IDs as strings, not `xs:ID`, so existing IDs are kept unchanged.
- Gate references are checked against the five IDs in the gate module (enumeration).

## Consequences
- A slice is valid only if it carries what it points to, so a slice can be read without the full study.
- Some definitions repeat across files; each file is generated by script from the same source (P3.S03), so they cannot drift.
