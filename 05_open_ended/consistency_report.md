# Consistency check (M17)

Generated by `scripts/p5_agreement.py`.

**Design.** 200 answers drawn at random from all 1,697, stratified by question (36 each from Q21–Q25, 20 'please specify'; `scripts/p5_draw_recode_sample.py`, seed 1954). A second coder — a separate agent that had not seen the main codes — coded them blind from the coding frame v1.1 alone. Agreement is measured on whether an answer is codable (all 200), then on each layer for the 94 answers both coders found codable: the primary code, and the presence of each code (multi-code agreement).

**Thresholds** (Scott, D5-2; Krippendorff 2004): alpha ≥ 0.80 reliable; 0.67–0.80 usable with caution; below 0.67 revise the definitions and re-check.
