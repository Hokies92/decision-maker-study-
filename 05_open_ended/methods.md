# Methods for the open-ended answers

Authored record (P5.S01). Scott's direction (2026-10-29): "factor in as many structured published ways to analyze opened feedback as possible so that we create lots of views and associations." Each method below is published; this file states what it is, how it is applied here, which questions it uses, and its limits on this corpus.

**Corpus.** 1,697 respondent-level text answers from 319 respondents: Q21 (what differentiates a vendor), Q22 / Q23 (the three most / least effective sales teams, and why), Q24 / Q25 (primary contact in the best / worst relationships, and why), and 105 "please specify" answers. Source: `03_schema/examples/respondents_open_ended.xml` (identical to SRC-002 / SRC-003). Answers are short — median 2–5 words; the longest stop near 255 characters (possible entry limit, P2.S06).

**Fixed rules.** Verbatims are never changed; codes live in separate files keyed by answer ID, respondent ID and question thread. No respondent is given a function, level or stakeholder type — none exists in the source. Codes assigned by Claude are `INFERRED`. All vendor and person names are kept and indexed (Scott, D5-4). Coding by Claude; agreement checked by an independent blind re-code (Scott, D5-1); Krippendorff's alpha ≥ 0.80 reliable, 0.67–0.80 usable with caution, < 0.67 revise (Scott, D5-2). An answer may carry several codes per layer, one marked primary (Scott, D5-3).

## How the methods combine

1. **Text views (M12–M15)** are scripted and need no judgment; they run first (P5.S02) and give the inductive pass something to check against.
2. **Coding layers (M1–M8, M10, M11)** are applied by hand, in one pass per answer: gate, behaviour, SERVQUAL, means-end, attribution, valence, lexicon concept, plus a not-codable flag.
3. **Classifications built from codes (M4, M5, M9, M16)** are computed by script in P5.S07 — CIT and satisfier / dissatisfier lists from behaviour × best / worst; the framework matrix and networks from codes × respondents.
4. **Reliability (M17)** decides which layers can carry findings.
